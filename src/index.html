Retrieved impact data and AI explanation

Object mass and map details are retrieved from Wikidata, OpenStreetMap, and optionally Google Maps Geocoding. Gemini summarizes those retrieved facts and the scenario; it does not predict physical damage, casualties, or impact probability. The orbital LSTM predicts TLE-derived motion only.

Select an object to start public data lookup. Missing mass or population will be shown as unknown.

Run the de-orbit scenario to retrieve impact evidence and request a Gemini summary. Configure GEMINI_API_KEY on the server to enable AI summaries.

Damage and casualties are not estimated without verified fragment survival, impact physics, weather, and local population data.

Select an object to start its background LSTM engine. It checks for new TLE history every two hours and retrains when new snapshots are available.
